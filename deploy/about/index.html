ComfyUI Web 是什么

不是单纯的 ComfyUI 套壳，而是面向二次元创作者的 选角 → 出图 → 写卡 工作站。把本地算力、云端兜底、海量角色 Trigger、画师标签，以及 SillyTavern 写卡收进同一个站点。

你能在这里做什么

  • 角色库 — 862 作品系列、30,609 角色 Trigger，点选插入提示词
  • 本地生图 — 连接 ComfyUI，Anima / SDXL 双架构，LoRA、ControlNet、高清放大等
  • 云端生图 — NAI API；DZMM 多账号池，没显卡也能画
  • 画师与标签 — 画师库、自定义画师串、标签浏览与翻译
  • 重绘与修图 — Anima 局部重绘、浏览器内抠图 / 图层合成、参数方案与 PNG 导入
  • 角色卡生成 — SillyTavern V2/V3、世界书、AI 助手，自备 LLM 同域可用
  • 资讯与教程 — 模型动态、CORS / Anima 上手指南，RSS 可订阅
