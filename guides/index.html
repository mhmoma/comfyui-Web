生图工具教程

适配 ComfyUI Web v5.01。按启动器加参数 → 连上本站 → 选架构填模型 → 出第一张图。纯小白可跟做。

1. 启动 ComfyUI（必加跨域）

一句话 启动时必须带 --enable-cors-header，本站网页才能访问你电脑上的 ComfyUI。推荐同时加 --preview-method auto。

A. 秋叶启动器

  1. 打开秋叶启动器。
  2. 左侧进入 高级选项（或「高级设置」）。
  3. 找到 自定义参数 / 额外启动参数 输入框。
  4. 粘贴下面整行（不要多复制前后空格），再点一键启动：
--enable-cors-header --preview-method auto

手机也要连同一台电脑时：

--enable-cors-header --preview-method auto --listen

填写位置：秋叶启动器 → 高级选项 → 自定义参数（不是本站设置页）。

B. Boat 启动器 / .bat 启动

Boat 等图形启动器：找「启动参数」「额外参数」文本框，粘贴与上面相同内容后启动。

.bat / .cmd：右键用记事本打开，找到含 main.py 的一行，在末尾追加参数并保存，再双击运行：

python main.py --enable-cors-header --preview-method auto

局域网：

python main.py --enable-cors-header --preview-method auto --listen 0.0.0.0

模型目录通常在启动器文件夹下的 ComfyUI/models/。

C. 命令行

python main.py --enable-cors-header --preview-method auto

2. 打开本站并连上

  1. 打开 生图工具。
  2. 点右上角 ⚙️ 设置。
  3. ComfyUI 地址填 http://127.0.0.1:8188（本机）。手机连电脑则填 http://电脑IP:8188，且启动时需 --listen。
  4. 看顶栏连接灯变绿即可。

地址填在本站 ⚙️ 里；CORS 参数填在启动器里——两处不要搞混。

3. 界面地图：参数在哪

新手请用左侧 简易模式。

  • 左侧 · 基础设置 — 架构、模型、采样器 / 步数 / CFG、宽高、种子
  • 左侧 · 增强功能 — VAE、LoRA、高清放大、FreeU（部分仅 SDXL）
  • 左侧 · 图像控制 — ControlNet、IP-Adapter、图生图（多仅 SDXL）
  • 左侧 · 后处理 — 面部修复等
  • 中间 · 提示词 — 正向 / 反向；可选角色与标签插入
  • 结果区 / 历史 — 出图预览与记录

应用内点顶栏 📖 也可打开同款教程弹窗（含一键下载模型）。

4. 模型架构怎么选、怎么填

位置：生图页左侧 → 基础设置 → 模型架构。

SDXL (Checkpoint)

  1. 架构选 SDXL (Checkpoint)。
  2. 在 Checkpoint 下拉框选模型（文件放在 models/checkpoints/）。
  3. 可选：增强功能里打开 VAE，另选 models/vae/ 中的文件。

推荐起步：采样器 euler · 调度器 normal · 步数 30 · CFG 6 · Clip Skip 2 · 尺寸 1024×1536。

可用：ControlNet、IP-Adapter、FreeU、加速模式、外部 VAE、LoRA、高清放大等。

Anima (Diffusion Model)

  1. 架构选 Anima (Diffusion Model)。
  2. 三个下拉框都要选：
    • 扩散模型 → models/diffusion_models/
    • 文本编码器 → models/text_encoders/
    • VAE → models/vae/
口诀 Anima = 画图模型 + 读词器 + 解码器，缺一不可。换扩散模型时，后两件常可共用。

推荐起步：euler · simple · 步数 30 · CFG 4 · Clip Skip 1 · 约 832×1216。

不可用（会自动隐藏）：ControlNet、IP-Adapter、FreeU、加速、SDXL 外部 VAE。局部重绘按 Anima 工作流设计。

Krea 2 同样选 Anima 架构加载（见应用内教程下载区）。

5. 第一次出图

  1. 连接灯为绿色。
  2. 选好架构与模型。
  3. 中间填写正向提示词（可点选角色 / 标签）。
  4. 可选填反向提示词；种子 -1 为随机。
  5. 点「生成图片」，在结果区等待。

提示词在中间大框，不在左侧采样参数里。

8. 局部重绘依赖

Anima 局部重绘需要自定义节点，例如：

  • FLS_Sampler（含 FLS_SamplerV4）
  • ComfyUI-CropAndStitch
  • ComfyUI_essentials
  • ComfyUI-Anima-LLLite 与 inpaint 权重
  • 若使用 Anima-2.9B：另装 ComfyUI-Anima-2.9B（加载器 patch，与 LLLite 并存）

可用项目里的安装脚本一键检查。装好后在 生图工具 从结果图 / 历史进入局部重绘。

10. 常见问题

  • 一直未连接 — 启动参数是否含 --enable-cors-header；地址是否为 http://127.0.0.1:8188；重启 ComfyUI 后刷新页面。
  • 模型下拉为空 — 文件是否放对文件夹；放完后刷新或重启 ComfyUI。
  • Anima 报错 — 三个下拉是否都已选择。
  • Anima 没有 ControlNet — 正常，请改用 SDXL。
  • 种子 -1 — 每次随机；固定数字便于复现。
